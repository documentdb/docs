# DocumentDB v0.110-0 Release Notes

DocumentDB `v0.110-0` was published on April 22, 2026 and is the current
release. Pre-built Linux packages and the `documentdb-local` container image
are available — see the
[Pre-built Packages](../getting-started/prebuilt-packages.md) page for
download and installation instructions.

## New features

### Administration commands

- **[`killSessions`](../api-reference/commands/administration/killSessions.md)** *(v0.110-0)* — terminate one or more client sessions explicitly, killing their cursors and rolling back their transactions.

### Security and RBAC

- **[Custom Roles](../api-reference/commands/security/customRoles.md)** *(v0.110-0)* — four new built-in PostgreSQL roles (`documentdb_api_find_role`, `documentdb_api_insert_role`, `documentdb_api_update_role`, `documentdb_api_remove_role`) that grant least-privilege access to the find, insert, update, and delete CRUD operations respectively.

### Query and aggregation

- **[`$jsonSchema`](../api-reference/operators/evaluation-query/$jsonschema.md)** now accepts the `description` keyword *(v0.110-0)*. The keyword is parsed and validated as a string and is treated as documentation only — it does not change validation results.

### Gateway and tooling

- **Arbitrary database user / password** *(v0.110-0)* — the gateway now accepts arbitrary username and password values when establishing client connections, removing previous restrictions on the credentials that can be used to authenticate against DocumentDB.
- **Cargo tooling for `pg_documentdb_gw`** *(v0.110-0)* — the Rust gateway is now built with cargo workspaces. The change is internal but lets downstream packagers and SBOM tooling enumerate the gateway's dependencies more reliably.

## Performance improvements

- **`$min` / `$max` accumulator optimization** *(v0.110-0)* — opt-in fast path for the `$min` and `$max` accumulators in `$group` and `$setWindowFields`. Enable per session with `SET documentdb.enableNewMinMaxAccumulators TO on;`. See [`$min`](../api-reference/operators/accumulators/$min.md) and [`$max`](../api-reference/operators/accumulators/$max.md).
- **TTL purge runs to budget** *(v0.110-0)* — the TTL background job now repeats batch deletes until its one-minute budget is exhausted, instead of doing one batch per index per minute. Reduces backlog on collections with many expiring documents.

## Behavior changes

- **TTL indexes use the composite opclass by default** *(v0.110-0)* — controlled by the new GUC `documentdb.createTTLIndexAsCompositeByDefault`.

## Bug fixes

The following crashes and behavioral bugs were fixed in this release; no client
changes are required.

- Fixed crash in `bson_dollar_lookup_project` when matched-documents arrays contained `NULL` elements from a `LEFT JOIN` (#465).
- Fixed crash in `$densify` with `partitionByFields` on a shard key when the partition expression was `INT8` (#464).
- Fixed crash in `shard_collection` when implicit collection creation failed and returned `NULL` (#462).
- Fixed crash in `$let` when the `in` expression was a constant (#463).
- Fixed crash in `$first`, `$last`, `$firstN`, and `$lastN` accumulators in a `$group` stage with no `$sort` when zero rows reached the accumulator (#466).

## Upgrade notes

- The `v0.110-0` release publishes Linux DEB and RPM packages for PostgreSQL 16, 17, and 18 on amd64/x86_64 and arm64/aarch64. macOS and Windows installers are not part of this release.
- The `documentdb-local` Docker image is published to GHCR at `ghcr.io/documentdb/documentdb/documentdb-local:latest`.
- Existing self-managed deployments are upgraded by installing the new package for the target PostgreSQL version and applying the bundled extension upgrade scripts for the deployment.
- See the upstream [CHANGELOG.md](https://github.com/documentdb/documentdb/blob/v0.110-0/CHANGELOG.md) for the canonical, line-by-line summary of changes that ship in this release.
